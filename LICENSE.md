**Ñefli** se ha desarrollado con fines **exclusivamente académicos y educativos**, como práctica de aprendizaje de arquitectura de microservicios, desarrollo de APIs REST, bases de datos y desarrollo web.

Los autores **no persiguen ningún fin comercial ni lucrativo** con este proyecto. No se comercializa, no se ofrece como servicio a terceros y no genera ningún tipo de ingreso.

### 4. Funcionalidad simulada

- La aplicación **no emite ni distribuye vídeo**: la reproducción es una simulación que solo registra estados en una base de datos.
- **No procesa pagos reales.** Los métodos de pago y las suscripciones son simulados.
- El proyecto **no está preparado para producción** y no implementa medidas de seguridad adecuadas: las contraseñas se guardan sin cifrar y no hay autenticación robusta. **No introduzcas datos personales ni bancarios reales.**
